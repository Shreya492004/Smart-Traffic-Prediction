Real-Time Traffic Prediction in Smart Cities Using Machine Learning

Traffic congestion is a major challenge in smart cities, affecting mobility, fuel consumption, and air pollution. Real-time traffic prediction is crucial for efficient transportation management and urban planning. Traditional forecasting methods struggle to handle dynamic and complex traffic patterns, which reduces accuracy. Therefore, machine learning techniques such as XGBoost are used to develop a real-time traffic prediction model. The dataset is collected from a computer vision model that detects vehicles every 15 minutes. The model provides accurate traffic flow forecasting, improves congestion management, helps optimize traffic signals, and supports data-driven urban mobility solutions. The main aim is to make smart cities more efficient, sustainable, and well-managed.
